# figures — 그림 39장

**결론**: 보고서에 실린 그림 14장은 모두 여기서 나온다. 아래 목록의 보고서 그림 번호 열이 그 대응이다.
`python run_all.py`가 끝나면 PNG와 색인이 생성된다. 전처리·학습·지표 수정 후에는 전체 그림을 다시 생성해 최신 표와 함께 사용한다. 기존 보고서에 붙인 그림이 자동으로 교체되는 것은 아니다.

- 파일 이름: `F{번호}_{제목}.png`. 그림마다 그 그림을 그린 원자료가 `outputs/tables/F{번호}_src.csv` 로 함께 저장된다(값을 확인하거나 다시 그릴 때 쓴다).
- `figure_index.csv` 의 열: `fid · 파일명 · 보고서절 · 제목 · 캡션 · 소스표`.
  **주의**: 이 파일의 `보고서절` 열은 이름과 달리 **코드 절 번호**(그림을 그린 `src` 의 절, 예 `1.5`)다. 보고서 그림 번호는 아래 표를 본다.
- 목록 보기: `python show_results.py --figures`. KAMP 파일 창에서 PNG 를 더블클릭하면 그림이 열린다.
- 한글이 □□□ 로 보이면 한글 폰트가 없었던 것이다(`bash check_env.sh` 6절). 폰트를 넣고 다시 실행한다.

## 수정본 그림 해석

- F17~F25의 성능·오차·보정 그림은 최신 예측을 기준으로 다시 계산한다. F21은 시간순 교차적합 평가이므로 전체 OOF에 적합한 보정기의 학습내 성능으로 해석하지 않는다.
- F33의 실패사례 설명은 과대·과소예측의 실제 방향을 따른다.
- F35~F38은 과거 실측 부하에 가정한 조치를 적용한 시나리오다. 전력량요금 절감은 산정에서 제외하고, 순절감의 비용·편익 기간을 관측기간으로 맞춘다. 연간 기본요금 환산액과 관측기간 순절감을 혼합하지 않는다.
- 부하 이동 후 222kW를 넘는 새 피크는 그대로 반영한다. 기존 상한 클리핑이 적용된 그림과 최신 그림을 섞어 사용하지 않는다.
- F39는 경보 활용 절차의 제안이며 자동 생산일정 최적화가 구현·실증됐다는 뜻이 아니다.

제출 PNG의 F36은 Windows 맑은 고딕에서 누락된 빼기 기호를 표시하기 위해 DejaVu Sans를 보조 글꼴로 사용해 재렌더링했다. 동일한 `plot_net_saving` 함수와 생성표를 사용했으며 계산값·원자료·제목은 바꾸지 않았다.
